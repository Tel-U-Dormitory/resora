# shadcn/ui

Calendar, Popover, Sidebar, Sheet, Avatar and use-mobile are adapted from the official Base Lyra registry at https://ui.shadcn.com/r/styles/base-lyra/. Unused optional primitives were omitted; RESORA adjusts labels, breakpoints, sizing and theme tokens.

# Uiverse / AHMED-MIT

Inline loading spinner adapted from AHMED-MIT's curly-rabbit-4.
Source: https://uiverse.io/AHMED-MIT/curly-rabbit-4
Repository source: https://github.com/uiverse-io/galaxy/blob/main/loaders/AHMED-MIT_curly-rabbit-4.html

RESORA scales the loader to inline dimensions, uses currentColor, renames classes/keyframes and supports reduced motion.

# Architecture / Product Decision Records

Records include `Accepted`, `Proposed`, and `Deferred` decisions. `Accepted` means the user/PM explicitly chose it, not that implementation has been shipped. A future decision that changes a record must add a new ADR rather than silently rewriting history. Record review date, consequences, and open verification.
